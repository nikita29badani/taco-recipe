# 🍽️ Recipe Selector Web App (Practice Project)

This is a beginner-level practice project built to strengthen my understanding of Node.js, Express.js, JSON handling, and EJS templating. The application allows users to select a protein type and dynamically displays the corresponding recipe using server-side rendering.

This project was created as part of my backend learning journey to understand how data flows between frontend, server, and templates.

---

## 🎯 Purpose of this Project

The main goal of this project was to practice and understand:

- How Express.js works
- How to handle POST requests
- How to use req.body to capture user input
- How to read and use JSON data as a data source
- How to send data from server to EJS templates
- How dynamic rendering works

## 🛠️ Tech Stack

- Node.js
- Express.js
- EJS
- HTML
- CSS
- JSON

## ⚙️ How to Run

### Install dependencies

npm install 

Run the server
node index.js

Open in browser
http://localhost:3000
